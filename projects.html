Secure IoT

SafePi

SafePi is a secure home security IoT device built as a CSUMB Computer Science capstone with Joseph Carey, Tomas Diaz Wahl, and Liam Cristescu. The system combined a Node.js server, OAuth2, an Android app, Bluetooth Low Energy provisioning in Kotlin, Wi-Fi sign-in, and a Raspberry Pi 4B running embedded Linux. The project received the CS Faculty Choice Award.

Self-hosting and privacy

Lightning Node

I built and maintained a Lightning node on a Raspberry Pi 4 using Umbrel. The node hosted a full Bitcoin blockchain copy, verified network data, supported Tor connections, and contributed as a Tor Snowflake relay. I am interested in the privacy and infrastructure lessons around the network more than speculation.

Web and music

SpaceIsDirty.com

SpaceIsDirty.com is a custom site for my music recording group, built with HTML, CSS, JavaScript, Flask, and NGINX on my home server. It started as an experiment with Tor hosting and grew into a full site with contact flows, mobile-specific media players, HTTPS certificates, secure server configuration, and practical application hosting work.

Radio

I am a General class amateur radio operator, KN6YCI. My radio projects span shortwave antennas, APRS packet radio, hardware experimentation, and ideas for long-range internet-less communication that connect directly to my wireless networking research.
